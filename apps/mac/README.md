# drop pour macOS

L'app de la barre de menus (T2.4, T3.4, D30) : une coque Tauri autour du Node, qui sert lui-même le panneau.

Pour essayer :

```sh
node scripts/build-mac.ts --debug
```

Construction signée et notarisée, mises à jour, retour arrière et recette : voir [docs/MAC_RELEASE.md](../../docs/MAC_RELEASE.md). C'est la seule procédure à suivre.
