Démarrer en 5 minutes

Installer une fois.
Demander en une phrase.

Une app pour répondre, un connecteur pour demander. Personne ne reçoit d'accès : seulement des réponses que leur propriétaire a autorisées.

Pendant la bêta, nous faisons ces étapes avec vous. L'app Mac attend sa signature Apple et le paquet public son nom définitif. Voici déjà le parcours tel qu'il se passera.

Avant de commencer.

drop relie des personnes d'une même équipe. Il faut :

  • pour répondre, un Mac avec puce Apple et macOS 13 ou plus récent ;
  • pour demander, Claude Code, Codex, Cursor, Claude Desktop, ou Claude et ChatGPT sur le web ;
  • un lien d'invitation envoyé par quelqu'un de l'équipe, ou créer l'équipe vous-même.

Pour répondre : l'app Mac.

Deux minutes. L'app vit dans la barre de menus et ne demande aucun terminal.

  1. Installez l'app et ouvrez-la. Elle crée votre identité à votre prénom, se connecte au relais et démarre avec votre session.
  2. Rejoignez l'équipe. Ouvrez le lien d'invitation reçu (il commence par drop://pair, valable 24 h, une seule fois). Ou créez l'équipe dans l'onglet Équipe, puis invitez les autres.
  3. Partagez vos outils. L'onglet Mes outils liste ce que drop a trouvé dans vos agents : Figma, Notion, Linear, GitHub… Pour chacun, choisissez les outils en lecture que vos collègues pourront faire utiliser.
  4. Décidez. Chaque demande s'affiche sous l'icône : qui demande, pourquoi, ce qu'il recevra et ce qu'il ne recevra jamais. Autoriser une fois, refuser, ou plus tard.

Pour demander depuis un agent de code.

Une minute. Dans l'onglet Mes outils de l'app, ajoutez drop aux agents détectés : Claude Code, Codex, Cursor ou Claude Desktop. Ou dans un terminal : 

drop install all

Redémarrez l'agent, puis demandez simplement : « Demande à mon équipe où en est la maquette du paiement. » drop choisit qui peut répondre, par le prénom cité ou par les outils partagés, et rassemble les réponses.

Pour Claude Desktop seul, le paquet drop.mcpb s'installe d'un double clic.

Pour demander depuis Claude ou ChatGPT.

Deux minutes, avec l'app drop installée sur le même Mac.

  1. Ajoutez le connecteur avec cette adresse : https://drop.memolabs.dev/mcp. Dans Claude : Réglages, Connecteurs, ajouter un connecteur personnalisé. Dans ChatGPT : le mode développeur des connecteurs, disponible selon votre abonnement.
  2. Autorisez dans l'app drop. La page de connexion ouvre l'app, qui affiche le nom de l'assistant et le domaine où partira l'autorisation : claude.ai ou chatgpt.com. Si c'est un autre domaine, l'app vous prévient : refusez si vous n'avez rien demandé.
  3. Posez votre question dans la conversation. Vos collègues décident comme pour un agent de code.

Le connecteur passe par la passerelle de drop, qui voit vos questions et les réponses en clair, comme Claude ou ChatGPT eux-mêmes. Elle n'en garde rien. En savoir plus

Et ensuite.

  • Un assistant relié se retire d'un clic dans l'onglet Mes outils.
  • Chaque échange laisse un reçu signé des deux côtés, sans le contenu.
  • Par défaut, celui qui demande paie le modèle qui répond, avec une clé plafonnée créée pour sa seule demande. Le plafond est affiché sur la carte.
