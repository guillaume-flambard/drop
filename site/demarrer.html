Pendant la bêta, nous faisons ces étapes avec vous. L'app Mac est signée et notarisée ; il reste à la tester sur un Mac neuf. Le paquet public attend son nom définitif. Voici déjà le parcours.

Avant de commencer.

drop relie des personnes d'une même équipe. Il faut :

  • pour répondre, un Mac avec puce Apple et macOS 13 ou plus récent ;
  • pour demander, un agent qui parle MCP : Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI, VS Code, Cline, ou l'un des six autres clients reconnus ;
  • un lien d'invitation envoyé par quelqu'un de l'équipe, ou créer l'équipe vous-même.

Pour répondre : l'app Mac.

Deux minutes. L'app vit dans la barre de menus et ne demande aucun terminal.

  1. Installez l'app et ouvrez-la. Elle crée votre identité à votre prénom, se connecte au relais et démarre avec votre session.
  2. Rejoignez l'équipe. Ouvrez le lien d'invitation reçu (il commence par https://drop.memolabs.dev/join#, valable 24 h, une seule fois). Ou créez l'équipe dans l'onglet Équipe, puis invitez les autres.
  3. Partagez vos outils. L'onglet Mes outils liste les serveurs MCP trouvés dans vos agents. Un interrupteur partage un serveur avec les seuls outils que ce serveur déclare en lecture. Choisir les outils, le modèle et la personne qui décide depuis l'app viendra plus tard ; en ligne de commande, drop share --tools permet déjà de nommer les outils. Vous pouvez aussi publier un fait : une information que vous acceptez de partager telle quelle, jusqu'à une date de fin.
  4. Décidez. Chaque demande s'affiche sous l'icône : qui demande, pourquoi, ce qu'il recevra, ce qu'il ne recevra jamais et quand la demande expire. Autoriser une fois, refuser, plus tard, ou répondre vous-même par un texte.

Pour demander depuis un agent de code.

Une minute. Dans l'onglet Mes outils de l'app, ajoutez drop aux agents détectés. Sept sont raccordés automatiquement : Claude Code, Claude Desktop, Cursor, Codex, Gemini CLI, VS Code et Cline. Pour les six autres, l'app affiche la configuration à copier. Ou dans un terminal : 

drop install all

Redémarrez l'agent, puis demandez simplement : « Demande à mon équipe où en est la maquette du paiement. » drop choisit qui peut répondre, par le prénom cité ou par les outils partagés, et rassemble les réponses.

Pour Claude Desktop seul, le paquet drop.mcpb s'installe d'un double clic.

Claude et ChatGPT sur le web : pas encore.

Ces assistants n'acceptent qu'un connecteur en ligne. Une passerelle existe dans le code, à l'adresse prévue https://drop.memolabs.dev/mcp, mais elle n'est pas livrée. C'est une option cloud, remise à plus tard.

Le profil privé, celui que crée l'app, refuse de se relier à cette passerelle. Une entreprise peut aussi l'interdire par sa politique. Pour demander, utilisez un agent installé sur votre poste. En savoir plus

Et ensuite.

  • Un agent raccordé se retire d'un clic dans l'onglet Mes outils.
  • Chaque échange laisse un reçu signé des deux côtés, sans le contenu.
  • Le modèle qui répond est le vôtre, sur votre poste ou dans votre entreprise. Le profil privé refuse toute clé envoyée par celui qui demande.
