# Getting help

drop is an early prototype maintained by one person. Answers are best effort.

| You want to                         | Go to                                                                                                         |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Ask a question or get help          | [Discussions, Q&A](https://github.com/guillaume-flambard/drop/discussions/categories/q-a)                     |
| Suggest an idea or discuss a design | [Discussions, Ideas](https://github.com/guillaume-flambard/drop/discussions/categories/ideas)                 |
| Report a reproducible bug           | [New bug report](https://github.com/guillaume-flambard/drop/issues/new?template=bug_report.yml)               |
| Propose a bounded feature           | [New feature request](https://github.com/guillaume-flambard/drop/issues/new?template=feature_request.yml)     |
| Report a vulnerability              | [Private security report](https://github.com/guillaume-flambard/drop/security/advisories/new), never an issue |
| Report a Code of Conduct problem    | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#enforcement)                                                      |

Before asking, check [README.md](README.md), the [guide](docs/GUIDE.md) (in French) and [existing issues](https://github.com/guillaume-flambard/drop/issues?q=is%3Aissue).

When you ask, include the commit you use, your OS, the agent and its version, and what you tried. Never paste keys, real configurations, conversations or anyone's data. There is no email support and no paid support at this stage.
