# T4.20 — Relier les scénarios AC du blocked-observer à leurs tests

## Situation

Le backlog `docs/TASKS.md` désigne une dette de traçabilité des critères OpenSpec. Dans `openspec/specs/blocked-observer/spec.md`, cinq scénarios `AC:` possèdent déjà des tests équivalents, mais les liens de preuve `openspec-guard:test` sont absents. Ils restent donc à tort dans les AC sans sélecteur exploitable.

## Tâche

Traiter **une sous-tâche T4.20**, en ajoutant uniquement les cinq liens vers les tests existants. Le contrat des tests, du produit, de la CLI et du protocole reste inchangé. Dépendance T4.19 terminée.

## Action avant implémentation

1. Vérifier exactement le nom de chaque `describe`/`it` et que chaque test exerce bien les conditions du scénario.
2. Ajouter sous chaque titre `AC:` un seul sélecteur OpenSpec correspondant ; ne pas inventer de test et ne pas supprimer les autres critères non reliés.
3. Lancer les tests du blocked-observer, `openspec-guard`, lint, typage et vérification du diff ; mettre à jour la baseline uniquement si elle ne fait que se réduire.
4. Ouvrir une PR soumise aux mêmes contrôles et passer le relais. **Ne pas** marquer tout T4.20 à `done` car des dizaines d’AC d’autres domaines restent à rapprocher.

## Résultat vérifié

- Les **5 scénarios AC** manquants de `blocked-observer` pointent désormais sur leurs cinq tests réellement présents, par sélecteur exact ; aucun test produit ou contrat runtime n'a été changé.
- `pnpm exec vitest run packages/blocked-observer/test/observer.test.ts packages/blocked-observer/test/store.test.ts` : **25/25 tests réussis**.
- `openspec-guard@0.3.0 --fail-on fail` : **540 AC liées par test**, 134 encore non liées dans le baseline ; ancien état 535 liées / 139 non liées sur cette branche. `--update-baseline` a retiré **exactement 5 entrées** sans aucun ajout (`+0, -5`).
- `pnpm -r lint`, `pnpm -r typecheck`, `git diff --check` : réussis.
- **T4.20 reste `todo` :** ces cinq preuves n'épuisent pas la dette de traçabilité des autres spécifications, et cette sous-tâche ne change pas le statut canonique.

## Passage de relais

Le prochain agent T4.20 doit choisir une autre famille de scénarios *déjà couverts par tests*, vérifier le nom exact des sélecteurs et réduire la baseline sans ajout, ou créer un test manquant lorsque la spécification l'exige. Ne pas lier un critère à un test qui ne couvre pas son comportement, ni marquer `done` sur la seule présence d'un marqueur.
